## 📚 What I've Learned

### 1. Node.js Fundamentals
- Understanding Node.js and how it works.
- Running JavaScript outside the browser.
- Working with command-line arguments.
- Using built-in modules like `fs` and `os`.
- Reading and writing files.
- Understanding synchronous and asynchronous operations.

### 2. JavaScript Modules & npm
- Creating and importing custom modules.
- Understanding CommonJS.
- Exporting functions and objects.
- Installing and managing npm packages.
- Working with `package.json` and `package-lock.json`.
- Creating npm scripts.

### 3. Asynchronous Programming
- Understanding synchronous and asynchronous code.
- Callbacks and callback functions.
- Promises: `resolve()`, `reject()`, `.then()` and `.catch()`.
- Async/await and error handling with try/catch.
- Understanding how asynchronous operations work.

### 4. HTTP & Express.js Fundamentals
- Understanding client-server communication.
- HTTP methods: GET, POST, PUT, PATCH and DELETE.
- HTTP status codes.
- Creating servers using Node.js HTTP module.
- Building servers with Express.js.
- Creating routes and handling requests.
- Sending text and JSON responses.
- Handling unknown routes with 404 status codes.

### 5. Express Routes & Parameters
- Creating dynamic routes.
- Understanding route parameters using `req.params`.
- Understanding query parameters using `req.query`.
- Reading IDs from URL paths.
- Filtering and searching using query parameters.
- Understanding the difference between route and query parameters.

### 6. Handling POST Requests
- Understanding POST requests.
- Creating POST routes using `app.post()`.
- Understanding request bodies using `req.body`.
- Using `express.json()` middleware to parse incoming JSON.
- Accessing submitted data such as usernames, product names and prices.
- Sending JSON responses using `res.json()`.
- Setting HTTP status codes using `res.status()`.
- Understanding HTTP status code `201 Created`.
- Understanding why one request should receive only one response.
