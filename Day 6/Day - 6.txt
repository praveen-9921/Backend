1. First, what is Express.js?
Yesterday, we created a server using Node.js's built-in http module.

It works perfectly!

But imagine building a website with 50 or 100 different routes.

Writing so many if/else conditions becomes difficult to manage.

Express.js solves this problem.

Express.js is a web framework for Node.js that makes it easier to:
- Create servers.
- Handle URLs and routes.
- Handle requests and responses.
- Build REST APIs.
- Add middleware.


Node.js gives us the environment to run JavaScript on the server.

Express.js gives us tools to build web servers and APIs more easily.

Sending JSON responses using Express
Yesterday we learned JSON.stringify() and res.setHeader() using Node's HTTP module.

Express makes this much easier with res.json().


Important: Express.js doesn't replace Node.js. Express runs on top of Node.js and uses its HTTP capabilities.
